# Data

No standalone dataset files were present in the repository during the organization review.

- The Titanic dataset is loaded by `src/data_analysis/making_data_whole.py` through Seaborn.
- The molecule dataset is defined inline by `src/modeling/decision_tree_classifier.py` and `src/data_analysis/molecule_solubility_dataframe.py`.
- Alkane boiling-point values are defined inline by `src/chemistry/alkane_boiling_points.py`.

The original files and their contents remain in their original locations.
